## 五、寄存器映射（bitblt_axi_slave，64 字节窗口 0x00–0x7C）

| 偏移 | 名称 | 说明 |
|---|---|---|
| 0x00 | CTRL | [0] START（自清零单拍）[1] IRQ_EN [2] SOFT_RST |
| 0x04 | STATUS | [0] BUSY [1] DONE [2] ERROR [3] addr_oob（只读）|
| 0x08–0x2C | OP/SRC_ADDR/DST_ADDR/WIDTH_H/SRC_STRIDE/DST_STRIDE/FILL_COLOR/ALPHA/KEY_COLOR/FRAME_CNT | 操作参数 |
| 0x30 | BPP | 字节/像素 |
| 0x34 | FB_BASE | 帧缓冲基址 |
| 0x38 | FB_SIZE_H | [15:0] 宽 [31:16] 高 |
| 0x3C | FB_CFG | [15:0] stride [16] enable |
| 0x40–0x50 | SPR_TABLE / SPR_CTL / SPR_RT_SEL / SPR_RT_BITS / SPR_RETIRE | 精灵表接口 |
| 0x54–0x58 | SPR_POS_IDX / SPR_POS_XY | 位置读回 |
| 0x5C | SCAN_STATUS | [0] blanking（只读）|
| 0x60–0x6C | MON_STICKY / MON_CNT_SEL / MON_CNT / MON_CTL | 片上断言监视 |
| 0x70 | SHORT_CNT | 扫描饥饿周期数（只读）|
| 0x74 | OOB_ADDR | 被拒地址（只读）|
| 0x78 | SCAN_FRAMES | 完成的帧数（只读）|
| 0x7C | SCAN_LINES | 上一帧有效行数（只读）|
| **0x80** | **SCAN_UNDERRUNS** | 行首无数据而开始的行数（**2026-10-27 新增**）|
| **0x84** | **SCAN_SHOWN** | 完整新帧数（无欠载，**2026-10-27 新增**）|
| **0x88** | **SCAN_AXI_ERR** | RRESP≠OKAY 的拍数（**2026-10-27 新增**）|

0x80 及以上由 `araddrReg[7]` 选择，走独立 `if` 分支；现有 0x00–0x7C 索引未移动。

& C:\Efinity\2026.1\bin\python3.bat ftdi_program.py -m jtag_bridge -b "Generic Board Profile Using FT4232H" `

# 写固件到 flash 0x380000

## 十、已知现象（客观描述）

### 10.1 画面抖动与撕裂

- 现象：屏幕出现“上半屏旧内容 / 下半屏新内容”的水平分界；有横向条纹带；有整屏闪烁。用户多次拍照/录像记录。
- 录像帧差分析数据（`work/video-frames/`）：
  - 2026-10-26 两段视频：亮度 130.6→181.2 单次阶跃；帧差均值 3.87 / 6.73。
  - 2026-10-26 第三段（42.7 s）：帧差均值 6.35，最大 66.2（第 1168–1200 帧）。
  - 2026-10-26 第四段（30.5 s）：帧差均值 **0.62**（画面几乎完全静止）。

### 10.2 慢态（读延迟）

- 现象：`DBG wto st=00000001` 反复出现；单次 blit 从 ~76 拍涨到 ~116,500 拍；帧时间从 294,000 涨到 21,947,851 拍。
- 实测：慢态下每次 DDR 读约 58,000 拍（docs/90）。
- 复现频率：`work/logs/` 中多次运行里约一半出现。

### 10.3 完全挂死

- 现象：串口停在 `copy-readback-1000x` 之后（约 1,169–1,321 字节处），120–150 秒无输出。
- 同期 openocd 报 `Halt timed out, wake up GDB` / `timed out while waiting for target halted`。
- 卡点在 `main.c:1363` 的 `blt_scan_wait_blanking(300000u)` 之前后（该处 `double buffering: A=... B=...` 不打印）。
- 该函数有 300,000 次轮询上限（约 366 ms），实测挂起远超此值。

### 10.4 `tb_bitblt_video_out` 失败内容

```
MISMATCH t=32260000 row=0 col=0 got=19934 exp=0
MISMATCH t=32260000 row=0 col=1 got=19943 exp=8
...
```
`got` 为 `row=19, col=934` 的期望值（19×1000+934=19934），即**行错位 19 行**。该 tb 的 AXI 从设备模型每 beat 间隔 2 拍（`r_gap=2`），pclk 为 148.5 MHz。

### 10.5 `copy-readback-1000x` 失败内容

- 失败时恒为 `mismatching pixels : 1024000`（= 1000 次 × 1024 像素，**每次全部不匹配**）。
- `last STATUS : 0x00000000`（无错误位、无 busy）。
- 该现象只在“health 固件”下出现；同一 bitstream 换回旧固件即为 0 错。未定位到代码级原因。

### 10.6 ESP32 无关项

- 板载 ESP32 未参与本项目；串口工具只使用 FT4232H 的 COM10。
