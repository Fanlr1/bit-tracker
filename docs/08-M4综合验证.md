## 二、★ DSP 推断结果（赛题硬指标）

**代码里只写了普通 `*`，综合器自动推断：**

```
### DSP Usage Report ###
|DSP    |TYPE |SIGNED|SHIFTER|BFLOAT|CAS_OUT|  O   |REGS|
|mult_10|DSP48|      |       |      |       |(A*B) |    |
|mult_17|DSP24|      |       |      |       |(A*B) |    |
|mult_20|DSP48|      |       |      |       |(A*B) |    |
|mult_27|DSP24|      |       |      |       |(A*B) |    |
|mult_30|DSP48|      |       |      |       |(A*B) |    |
|mult_7 |DSP24|      |       |      |       |(A*B) |    |
```

| 推断出的乘法器 | 对应代码 | 说明 |
|---|---|---|
| **3 × DSP48** | `fg_ch * eff_alpha`（三个颜色通道各一个）| 8bit × 8bit |
| **3 × DSP24** | `bg_ch * (255 - eff_alpha)`（三个通道各一个）| 8bit × 8bit |

**⇒ 赛题要求的「利用内部 DSP/硬件乘法器」自动满足，无需手工实例化 `EFX_DSP48`。**

### 为什么这样最好

| 做法 | 可仿真性 | 可读性 | 结果 |
|---|---|---|---|
| 手写 `EFX_DSP48` 原语 | 需加载 Efinity 加密/行为模型 | 差 | — |
| **写普通 `*`（当前做法）** | ✅ 纯 RTL，两套仿真器都能跑 | ✅ | **自动落到 DSP48/DSP24** |

## 四、复现方法

```powershell
# 工程目录（纯 ASCII，Efinity 在中文路径下的行为未验证，不冒险）
C:\fpga_work\syn\
  ├── bitblt_syn_test.xml         # 照 01_Key_led_osc_demo 的格式改的
  ├── src\bitblt_pixel_engine.v   # 从工作区 rtl\ 复制
  └── sdc\bitblt_syn_test.sdc     # create_clock 100 MHz

# 跑综合
cd C:\fpga_work\syn
C:\Efinity\2026.1\bin\efx_run.bat bitblt_syn_test.xml --flow map

# 看报告
outflow\bitblt_syn_test.map.rpt     # 内含 DSP Usage Report + Resource Summary
```

**工程文件相对 `01_Ti60F225_Key_led_osc_demo` 的改动**：

| 项 | 模板值 | 改为 |
|---|---|---|
| `top_module` | `LED_8bit_Test` | `bitblt_pixel_engine` |
| `design_file` | 3 个（顶层 + 2 子模块） | 1 个 |
| `timing_model` | **`C4`** | **`I3`**（与实板一致）|
| `sdc_file` | `src/sdc/LED_8bit_Test.pt.sdc` | `sdc/bitblt_syn_test.sdc` |
| `<efx:debugger>` 段 | 引用 `debug_profile.wizard.json` | **删除**（我们没有该文件）|
