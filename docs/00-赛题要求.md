## 二、赛题背景（选题指南 第 7 页 · 与讲解稿一致）

早期 2D 游戏机与现代嵌入式 GUI 中，完全依靠 CPU 死循环逐像素搬运渲染，**极大占用 CPU 资源、帧率骤降**。核心趋势是「**异构计算与软硬件协同设计（HW/SW Co-design）**」。

**本赛题要求**：基于 **RISC-V + FPGA 异构平台**设计定制硬件 2D 渲染加速器，**把 RISC-V 从像素搬运中解放出来** —— RISC-V 仅负责高层逻辑与下发指令，FPGA 硬件端完成底层像素的高速搬运与混合。

## 四、基础要求（必做 · 保底分）

> *考察总线协议、视频时序、软硬接口的基础掌握能力*

### 1. 硬件 2D 位块传输（BitBlt）引擎设计

| 项 | 要求 |
|---|---|
| 指令解析 | 解析 RISC-V 发送的渲染指令，**须包含：操作类型、源地址、目的地址、宽度、高度** |
| 支持操作 | **图像块拷贝（Block Copy）** + **纯色填充（Solid Fill）** |
| 视频输出 | 生成标准 **VGA/HDMI 时序**，将显存内容输出至显示器，**最低 640×480 @ 60Hz** |

### 2. 总线读写与存储器优化

- 加速器**必须通过系统总线直接访问内存**
- 合理使用**突发传输（Burst Transfer）** 与**内部 FIFO 缓存**，提高内存带宽利用率

### 3. 软件驱动与基础 Demo

- RISC-V 端需编写 **C 语言驱动程序**配置寄存器
- 实现**双缓冲机制（Double Buffering）** 避免画面撕裂（Tearing）
- 基础测试 Demo（例：大量方块随机移动、多张大图快速切换）
- **屏幕上实时对比显示「纯软件 CPU 渲染」与「硬件加速渲染」的帧率差异**

## 五、高阶挑战（加分项 · **完成度越高，得分越高**）

> *要求实现现代 2D 游戏引擎中的高级图层渲染管道*

### 1. 硬件 Alpha 混合（Hardware Alpha Blending）

FPGA 加速器搬运**前景图层（Sprite）** 时，利用**内部 DSP / 硬件乘法器**实时读取背景像素并混合：

```
输出像素 = 前景像素 × Alpha + 背景像素 × (1 - Alpha)
```

### 2. 颜色键控去背（Color Keying）

硬件支持设定「**透明色**」（如**纯品红色**），搬运时**自动跳过透明色像素**，实现**不规则边缘精灵图（Sprite）的完美渲染**。

### 3. 高负载互动游戏 Demo

| 项 | 要求 |
|---|---|
| 游戏类型 | **极高同屏元素数量** —— 《吸血鬼幸存者》简化版 / 《东方 Project》类弹幕射击 |
| 运行位置 | **RISC-V 上** |
| 挑战指标 | 开启硬件加速（Alpha 混合 + Color Keying）时，**保持 60 FPS 的同屏活动 Sprite 数量极限** |

## 八、由赛题反推的架构（初步，待 subagent 摸排后修订）

```
        RISC-V (Sapphire SoC)
              │
              │ AXI4 Master（下发渲染指令：操作类型/源地址/目的地址/宽/高）
              ▼
   ┌──────────────────────────────┐
   │   BitBlt 引擎（AXI4 从设备）    │
   │  · 指令寄存器组 / 命令 FIFO     │
   │  · Block Copy                 │
   │  · Solid Fill                 │
   │  · Alpha 混合（用 DSP 原语）    │
   │  · Color Keying               │
   │  · 内部 FIFO + Burst 突发       │
   └───────────┬──────────────────┘
               │ AXI4 Master（突发读写）
               ▼
        DDR3 控制器 ←→ DDR3 颗粒
               │
               ▼
        Framebuffer（显存区，双缓冲）
               │ 读像素
               ▼
        HDMI TX（时序生成 + TMDS 编码）
               │
               ▼
             显示器
```
