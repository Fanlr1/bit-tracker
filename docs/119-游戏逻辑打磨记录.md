## 已完成改动（commit 1d916af）

| 项 | 改动 | 原因 |
|---|---|---|
| 难度曲线 | `g_diff = g_sec / 30` → `g_sec / 45` | 原来 30 秒一档太陡，5 分钟时难度 10 档；改后 45 秒一档 |
| 敌人速度成长 | `g_diff * 2` → `g_diff * 3 / 2` | 配合难度曲线，速度增长放缓 |
| 波次规模 | `n = 2 + g_diff/2` → `2 + g_sec/60` | 波次大小与速度成长解耦，避免后期突然暴增 |
| 低血警告 | HUD 第一行文字生命 ≤45 时变红（0xF800）| 玩家低血时明确警示 |
