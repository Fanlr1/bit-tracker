## 一、为什么要做全链路

**⇒ 回归和综合原本是【分开跑的】，所以存在一个真实缺口：改动可以【通过全部 16 个测试台，却在综合时炸掉】。**

**⇒ 这不是假设 —— `async_fifo_gray` 的组合读版本就做到了**：

| 阶段 | 结果 |
|---|---|
| **`tb_async_fifo_gray`** | ✅ **153 项全过** |
| **`tb_bitblt_video_out`** | ✅ **95996 项全过** |
| **`map`** | **LUT4 11874 → 55072，耗时 528 s** |
| **`pnr`** | **❌ FAILED** |

**⇒ 仿真器不在乎你烧掉多少 LUT。** **⇒ 所以必须有一条命令，把「仿真」和「综合」串起来跑。**

### 为什么删掉而不是修好它

| 理由 | 说明 |
|---|---|
| **它会稳定报 29 个假错** | **一个总在喊狼的检查，人会学会直接翻过去 —— 然后真错也一起漏掉** |
| **语法其实已被覆盖两次** | **阶段 2 编译并精细化 16 个测试台（覆盖我们维护的全部模块）；阶段 3 的 `map` 才是包含厂商 IP 的全量语法+精细化关口** |
| **保留它等于重复且做错** | —— |

**⇒ 现在阶段 1 只报告「下游会覆盖什么」，不再自作主张地做语法判定。**

## 五、顺手修掉：两个测试台目录的重复文件

### 5.1 问题

**⇒ 两个目录都存着测试台**（`sys\tb\` 与 `tb\`），**其中有 3 组同名**：

| 文件 | 状态 |
|---|---|
| **`tb_bitblt_axi_slave.v`** | **两边内容相同** |
| **`tb_bitblt_video_out.v`** | **两边内容相同** |
| **`tb_bitblt_top.v`** | **⚠️ `sys\tb` 768 行 vs `tb\` 611 行 —— 内容不同** |

**⇒ 而 `run-regression.ps1` 用的是 `Sort-Object Name -Unique`，【静默保留先看到的那个】。**

**🚨 所以当时跑的是 768 行的正确版本，纯粹是因为 `sys\tb` 在搜索列表里排在前面 —— 这是【参数顺序的性质】，不是【文件的性质】。** **⇒ 把列表顺序一换，611 行的截断版就成了正式测试，而且不会有任何提示。** **⇒ 那个 611 行版正是早先一次文件截断事故留下的副本。**

### 5.2 修法

**① 把旧副本同步成新的**（`tb\ ← sys\tb`，旧版备份为 `.bak-20261006-truncated`），**并同步到工作区。**

**② 把【静默去重】改成【显式判定 + 分歧告警】**：

```powershell
if ($seen.ContainsKey($f.Name)) {
    $prev = $seen[$f.Name]
    if ((Get-FileHash $prev.FullName).Hash -ne (Get-FileHash $f.FullName).Hash) {
        $dupDiff++
        Write-Host ('  *** DUPLICATE, DIFFERENT CONTENT: ' + $f.Name) -ForegroundColor Red
        Write-Host ('        using  : ' + $prev.FullName)
        Write-Host ('        ignored: ' + $f.FullName)
    }
} else { $seen[$f.Name] = $f; $tbs += $f }
```

**⇒ 保留「靠前目录优先」的既有行为，但【内容不同时必须出声】。**

### 5.3 验证（制造分歧再恢复）

**⇒ 光改不测等于没改，所以人为制造了一次分歧**：往 `tb\tb_bitblt_video_out.v` 追加一行注释（该文件 `sys\tb` 里也有一份）。

```
*** DUPLICATE, DIFFERENT CONTENT: tb_bitblt_video_out.v
using  : C:\fpga_work\sys\tb\tb_bitblt_video_out.v
ignored: C:\fpga_work\tb\tb_bitblt_video_out.v
1 duplicated name(s) diverged -- reconcile them, do not rely on
  directory order to pick the right one.

Discovered 16 testbench(es):   PASS=16  FAIL=0   REGRESSION: PASS
```

**⇒ 告警生效，且指明了用了哪个、忽略了哪个。恢复后三个重名文件两两一致，无污染残留。**

**⚠️ 途中我第一次改错了文件**（改的是 `tb_counter.v`，它只在 `tb\` 里、本就不重名）**⇒ 没告警是【正确行为】，反而说明检查没有误报。**
