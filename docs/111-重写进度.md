## 二、关键设计点（与旧版差异）

| 项 | 旧 | 新 |
|---|---|---|
| AXI 主设备 | 4（源读/背景读/写/扫描） | **1**（全部共享） |
| R 通道死锁 | 任一从设备 rready=0 即锁死 | 一次一突发、客户端先备空间、rready 在整个突发内为 1 |
| 扫描行缓冲 | FWFT FIFO 流式 | **双行 bank + 行首 row_ok** |
| 帧序号 | 无 | **epoch**，行标签不匹配则整行黑 |
| 翻页 | 写 FB_BASE | **commit/accept + 帧首生效** |
| 命令提交 | 每条等完成 | **8 深 FIFO**，CPU 可连续下发 |
| 观测 | 仅 FPS | **underruns / shown / axi_errors / frames / lines** |
